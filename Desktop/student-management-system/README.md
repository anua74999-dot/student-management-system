# Student Management System

A Python-based Web Application built using **Streamlit** that enables efficient student record management using Object-Oriented Programming (OOP) principles, robust JSON file handling, exception handling, and filtering.

## 🚀 Key Features
* **Student CRUD Operations**: Create, Read, Update, and Delete student records cleanly.
* **OOP Design**: Utilizes classes (`Student`, `StudentManager`, `DataStorage`) with clean modular principles.
* **File Handling**: Persistent data storage powered by JSON files (`data/students.json`).
* **Search & Filter**: Real-time filtering by course and keyword matching for names or IDs.
* **Exception Handling**: Safe user validation, error wrapping, and persistent storage fallbacks.
